三步拿到 Key，把请求切到 OpenAchieve。

流程尽量短：注册即获 Free Key；需要更多模型时升级至 Plus。

1

注册

创建 OpenAchieve 账号，进入控制台准备管理项目 Key。

2

选择套餐

Free 可用实时同步的免费模型池；Plus {{PLUS_MONTHLY_PRICE_TEXT}}，开放主流模型池。

3

获取 Key

复制 API Key，替换 base_url 后继续使用原有 OpenAI 格式代码。

openai-compatible.ts 
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.OPENACHIEVE_KEY,
  baseURL: "https://openachieve.asia/v1"
});

const res = await client.chat.completions.create({
  model: "qwen3.6-plus",
  messages: [{ role: "user", content: "生成一个接入说明" }]
});
