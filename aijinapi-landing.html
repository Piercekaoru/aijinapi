Quick Start

三步拿到 Key，把请求切到 AIJinAPI。

流程尽量短：注册账号拿到 Free Key；需要主流模型时后台开通 Plus。

1

注册

创建 AIJinAPI 账号，进入控制台准备管理项目 Key。

2

选择套餐

Free 仅 Big Pickle；Plus 每月 13 美元开放主流模型池。

3

获取 Key

复制 API Key，替换 base_url 后继续使用原有 OpenAI 格式代码。

openai-compatible.ts 
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.AIJINAPI_KEY,
  baseURL: "https://api.aijinapi.com/v1"
});

const res = await client.chat.completions.create({
  model: "qwen3.6-plus",
  messages: [{ role: "user", content: "生成一个接入说明" }]
});
