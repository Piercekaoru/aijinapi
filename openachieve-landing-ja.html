Quick Start

3 ステップで Key を取得し、リクエストを OpenAchieve に切替。

最短フロー：登録で Free Key を取得。より多くのモデルが必要なら Plus にアップグレード。

1

登録

OpenAchieve アカウントを作成し、コンソールでプロジェクト Key を管理。

2

Key を取得

コンソールで API Key を生成。データベースにはハッシュのみ保存。

3

接続

base_url を OpenAchieve に差し替え、通常の OpenAI SDK で呼び出し。

2

选择套餐

Free は 5 つの無料モデルを利用可能。Plus は $13/月で主要モデルプールを利用できます。

3

获取 Key

复制 API Key，替换 base_url 后继续使用原有 OpenAI 格式代码。

openai-compatible.ts 
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.OPENACHIEVE_KEY,
  baseURL: "https://openachieve.asia/v1"
});

const res = await client.chat.completions.create({
  model: "qwen3.6-plus",
  messages: [{ role: "user", content: "生成一个接入说明" }]
});
